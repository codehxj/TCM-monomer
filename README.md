# Research Data and Supplementary Materials

This repository contains data, supplementary materials, and analysis files associated with our research article.

## Contents

- `.csv` or `.xlsx` — processed data used in the analyses
- `supplementary/` — supplementary tables and supporting materials
- `submission_figures/` — figure-related source data
- `code/` — scripts used for data processing, analysis, and visualization

## Data Description

The files in this repository support the analyses reported in the associated research article. The repository includes processed datasets, supplementary results, figure source data, and computational scripts that can be shared publicly.

## Reproducibility

Analysis scripts are provided where applicable to facilitate reproduction of the reported analyses and figures.

## Data Availability

The publicly shareable data and supplementary materials are available in this repository.

## Citation

If you use the data or code in this repository, please cite the associated research article after publication.
